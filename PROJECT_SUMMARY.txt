4. Browser opens to: http://localhost:5000

CUSTOMIZATION:
═════════════
Want to change something?

Colors     → Edit CSS in templates/base.html
Products   → Update PRODUCTS dict in app.py
Contact    → Update CONTACT_INFO in app.py
Layout     → Modify HTML files in templates/
Images     → Replace files in static/images/

TROUBLESHOOTING:
═══════════════
Q: Port 5000 in use?
A: Change port in app.py (last line) to 8000

Q: Missing modules?
A: Run: pip install -r requirements.txt

Q: Images not showing?
A: Run: python extract_images.py
