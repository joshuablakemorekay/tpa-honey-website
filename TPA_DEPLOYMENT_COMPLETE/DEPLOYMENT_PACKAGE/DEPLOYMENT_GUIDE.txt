═══════════════════════════════════════════════════════════════════
PHASE 2: UPLOAD TO GITHUB
═══════════════════════════════════════════════════════════════════

STEP 2: Create GitHub Account
───────────────────────────────────────────────────────────────────

1. Go to: https://github.com
2. Click "Sign up" (top right)
3. Create your account (it's free!)
4. Verify your email address

✅ Done? Your GitHub username: __________________

STEP 3: Install Git on Your Computer
───────────────────────────────────────────────────────────────────

**Windows:**
1. Download: https://git-scm.com/download/win
2. Run installer (accept all defaults)
3. Restart computer

**Mac:**
1. Open Terminal
2. Type: git --version
3. If not installed, it will prompt you to install

**Linux:**
```bash
sudo apt-get install git
```

To verify Git is installed:
```bash
git --version
```
Should show: git version 2.x.x

STEP 4: Configure Git
───────────────────────────────────────────────────────────────────

Open Terminal/Command Prompt and run:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

Replace with your actual name and email!

STEP 5: Create GitHub Repository
───────────────────────────────────────────────────────────────────

1. Go to GitHub.com and log in
2. Click the "+" icon (top right) → "New repository"
3. Fill in:
   - Repository name: tpa-honey-website
   - Description: T.P.A. Honey Farm Website - ฟาร์มผึ้งเทพภักดี
   - Public or Private: Choose "Public" (so Render can access it)
   - ⚠️ DO NOT check "Initialize with README"
4. Click "Create repository"

✅ Done? Your repository URL: 
https://github.com/YOUR_USERNAME/tpa-honey-website

STEP 6: Upload Your Project to GitHub
───────────────────────────────────────────────────────────────────

Open Terminal/Command Prompt and navigate to your project folder:

```bash
cd C:\Users\joshk\Downloads\Web App No. 2\tpa_honey_website\tpa_honey_website
```
(Adjust path to match your actual location!)

Then run these commands ONE BY ONE:

```bash
# Initialize Git repository
git init

# Add all files
git add .

# Create first commit
git commit -m "Initial commit - T.P.A. Honey Farm Website"

# Connect to GitHub (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/tpa-honey-website.git

# Upload to GitHub
git branch -M main
git push -u origin main
```

⚠️ You'll be asked for GitHub username and password:
- Username: your GitHub username
- Password: Create a Personal Access Token (see note below)

**Creating Personal Access Token:**
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name: "Render Deployment"
4. Check: "repo" (full control)
5. Click "Generate token"
6. Copy the token (you won't see it again!)
7. Use this token as your password

✅ Done? Refresh your GitHub repository page to see your files!

═══════════════════════════════════════════════════════════════════
PHASE 3: DEPLOY TO RENDER.COM
═══════════════════════════════════════════════════════════════════

STEP 7: Create Render Account
───────────────────────────────────────────────────────────────────

1. Go to: https://render.com
2. Click "Get Started" or "Sign Up"
3. Choose "Sign up with GitHub" (easiest option)
4. Authorize Render to access your GitHub
5. Verify your email

✅ Done? You're logged into Render!

STEP 8: Deploy Your Website
───────────────────────────────────────────────────────────────────

1. In Render Dashboard, click "New +" (top right)
2. Select "Web Service"
3. Click "Connect" next to your GitHub account
4. Find "tpa-honey-website" and click "Connect"
5. Fill in deployment settings:

   **Name**: tpa-honey-farm
   (This will be part of your URL)
   
   **Environment**: Python 3
   
   **Build Command**: pip install -r requirements.txt
   (Should auto-fill from render.yaml)
   
   **Start Command**: gunicorn app:app
   (Should auto-fill from render.yaml)
   
   **Instance Type**: Free

6. Click "Create Web Service"

🎉 Render will now deploy your website!

STEP 9: Wait for Deployment
───────────────────────────────────────────────────────────────────

Watch the deployment logs. You'll see:
- Installing Python packages
- Setting up Flask
- Starting your app

This takes ~5-10 minutes on first deploy.

When you see:
✅ "Deploy successful" or "Live"

Your website is LIVE! 🎉

STEP 10: Get Your Website URL
───────────────────────────────────────────────────────────────────

Your website URL will be:
https://tpa-honey-farm.onrender.com

(Or whatever name you chose in Step 8)

Click the URL to view your live website! 🌐

🔄 UPDATING YOUR WEBSITE

Whenever you want to update your website:

1. Make changes in PyCharm (edit files locally)
2. Open Terminal in your project folder
3. Run these commands:

```bash
git add .
git commit -m "Updated gallery images"
git push
```

4. Render automatically detects changes and redeploys!
5. Wait ~2-3 minutes for changes to go live

No need to repeat the entire process!

🆘 TROUBLESHOOTING

**Problem: Git push fails**
Solution: Make sure you're using Personal Access Token as password

**Problem: Render build fails**
Solution: Check that requirements.txt is in project root folder

**Problem: Website shows error**
Solution: Check Render logs for error messages

**Problem: Images don't load**
Solution: Make sure all images are in static/images/ folder

**Problem: 404 errors**
Solution: Verify all template files are in templates/ folder

Need more help? Check Render documentation:
https://render.com/docs/deploy-flask
