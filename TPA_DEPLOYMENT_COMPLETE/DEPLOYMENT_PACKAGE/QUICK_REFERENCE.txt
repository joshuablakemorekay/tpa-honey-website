💻 GIT COMMANDS (Run in Terminal)

1. Navigate to your project:
```bash
cd C:\Users\joshk\Downloads\Web App No. 2\tpa_honey_website\tpa_honey_website
```

2. Configure Git (first time only):
```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

3. Upload to GitHub:
```bash
git init
git add .
git commit -m "Initial commit - T.P.A. Honey Farm"
git remote add origin https://github.com/YOUR_USERNAME/tpa-honey-website.git
git branch -M main
git push -u origin main
```

4. Update website later:
```bash
git add .
git commit -m "Your update message"
git push
```

🆘 COMMON ISSUES

Problem: "Permission denied" when pushing to GitHub
Solution: Use Personal Access Token as password

Problem: Website shows "Application failed to respond"
Solution: Check Render logs, verify requirements.txt exists

Problem: Images not loading
Solution: Ensure images are in static/images/ folder

Problem: 404 errors
Solution: Check templates/ folder has all HTML files

🔄 UPDATE WORKFLOW

Every time you want to update:

1. Make changes in PyCharm
2. Save files
3. Run:
   ```bash
   git add .
   git commit -m "Description of changes"
   git push
   ```
4. Wait 2-3 minutes
5. Website auto-updates!
